# Documentación del Proyecto Precios

Este directorio contiene la documentación principal y específica de cada subproyecto.

## Estructura

- `back/`: Documentación del backend
- `front/`: Documentación del frontend

Cada subdirectorio contiene:
- `README.md`: Descripción general del subproyecto
- `arquitectura.md`: Diseño arquitectónico
- `definicion_tecnica.md`: Especificación técnica
- `endpoints.md`: Documentación de endpoints (solo backend/API)

- [Frontend](./front/README.md)

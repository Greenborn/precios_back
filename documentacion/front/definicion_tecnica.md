# Definición Técnica del Frontend

Este documento especifica los detalles técnicos del frontend de forma abstracta para permitir su reconstrucción en otra tecnología.

## Tecnologías Utilizadas
- Vue.js
- Vite
- Sass/SCSS

## Estructura de Carpetas
- `src/components/`: Componentes de la interfaz
- `src/pages/`: Vistas principales
- `src/api/`: Lógica de comunicación con el backend
- `src/stores/`: Gestión de estado
- `src/assets/`: Recursos estáticos
